# Planner Templates

Planner produces Epics, Work Orders, a context graph, and execution phases.

Use the canonical templates in this directory:

- Work Order template: `templates/planner/work-order-template.md`
- Context graph template: `templates/planner/context-graph-template.md`
- Work Order gates: `quality-gates/planner.md`

Production additions:

- Score each Work Order for executability.
- Add local verification instructions to every Work Order.
- Record execution phase approval in `docs/prd-to-work-orders/approvals.md`.
- Record Work Order count, graph defects, and executability in `docs/prd-to-work-orders/metrics.md`.
