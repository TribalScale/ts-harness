# Refinery Templates

Refinery produces product overview documents, FRDs, a feature tree, assumptions, and consistency reports.

Use the canonical templates in this directory:

- Product overview template: `templates/refinery/product-overview-template.md`
- FRD template: `templates/refinery/frd-template.md`
- Feature tree template: `templates/refinery/feature-tree-template.md`
- FRD quality gates: `quality-gates/refinery.md`

Production additions:

- Copy every open assumption into `docs/prd-to-work-orders/manifest.json`.
- Record gap and feature-tree approvals in `docs/prd-to-work-orders/approvals.md`.
- Record PRD coverage and AC testability in `docs/prd-to-work-orders/metrics.md`.
