# Product Overview Templates

Create six overview documents in `docs/refinery/overview/`.

## business-problem.md

```markdown
# Business Problem

## Problem Statement

[What business/user problem this product solves.]

## Pain Points

- [Pain point]

## Product Hypothesis

[Why this product should solve the problem.]
```

## current-state.md

```markdown
# Current State

[How users solve the problem today and what is broken.]
```

## personas.md

```markdown
# Personas

## [Persona Name]

- **Goals:** [Goals]
- **Frustrations:** [Frustrations]
- **Success looks like:** [Success criteria]
```

## product-description.md

```markdown
# Product Description

## What This Product Is

[Plain-language product summary.]

## How the Parts Fit Together

[Major product areas and relationships.]
```

## success-metrics.md

```markdown
# Success Metrics

| Metric | Definition | Target |
|---|---|---|
| [Metric] | [Definition] | [Target] |
```

## technical-requirements.md

```markdown
# Technical Requirements

## Constraints

[Mandatory regulatory, security, performance, platform constraints.]

## Preferences

[Architecture inputs for Foundry.]

## Non-Functional Requirements

[System-level testable NFRs.]
```
